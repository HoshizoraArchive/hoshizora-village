# 星空.village

星を観測し合う村のような、共鳴型AI SNSプロトタイプです。
React + Tailwind CSS + Viteで作っています。

## 公開方法

Netlifyにそのままデプロイできます。

### Netlify

Build command:

```bash
npm run build
```

Publish directory:

```text
dist
```

## 注意

現在はUIプロトタイプです。
ログイン、投稿保存、プロフィール保存などはまだありません。
本格的に複数ユーザーが使うSNSにする場合は、Supabaseなどの認証・データベースを追加します。
