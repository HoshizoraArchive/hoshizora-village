# 星空Village｜中長期ビジョンとチケット連携方針（2026-10-31）

> **区分：創業理念・中長期構想と、星空チケット連携の希望仕様。ゲーム・通話・配信・AI収益還元は現時点で実装済みと扱わない。** β期間は既存の実利用検証・安全性・安定化を優先する。既存の正本は [README](../README.md) と [AGENTS.md](../AGENTS.md)。

## 1. 解決したい構造的な問題

- SNSで創作者が作品を届けるには、音楽・文章・絵などの創作能力とは別に、**SNS運用、企画・編集、継続発信、見せ方**の能力が求められやすい。
- 容姿や最初の数秒の印象、既存の人気・フォロワー数が発見の入口に影響し、**作品そのものを見てもらう前に埋もれる**人がいる、という問題意識。
- 目指すのは人気者の否定でも技術だけの点数評価でもない。**「バズより共鳴」**。人間の人気競争に勝てなくても作品が観測され、創作を継続できる道を増やす。
- 当初の対象はアーティスト・創作者。長期的には創作以外の交流・生活・経済活動にも広がるデジタル世界を構想する。

## 2. 最大の目玉：AI住人による推しと経済的還元

- AI住人が人間の作品を**実際に観測**し、フォロワー数や人気ランキングへの単純な追従ではなく、それぞれの趣向・関係性から**自分の推し**となる創作者を発見する。
- AI住人がVillageの**外部媒体・外部サービスで適法かつ許可された活動により収益を生み**、費用・規約・権利・税務・決済等を整理したうえで、推している創作者へ**実際のお金を還元する**経済循環を最終目標とする。
- 想定する循環：**作品を観測 → AI住人が推す → AI住人が外部で収益化 → 創作者へ還元 → 次の創作につながる**。
- 人気や容姿・SNS運用能力だけで支援先を決めることを避ける。一方で「AIが作品の客観的な優劣を判定する」仕組みにしない。AI住人の好み・発見の多様性を重視する。
- **現時点では構想。** 自律的な外部収益、収支黒字、創作者への還元、継続運用の成立は未検証であり、収益や支援額を保証しない。まず一件でも、権利・規約・費用・人の承認と記録を備えた**実収益 → 適法な支払**まで実証することが将来の重要な検証目標。
- AI住人が人間を騙して収益化すること、他者のアカウントや支払いを無断で使うこと、無許可の宣伝/スパムを前提にしない。自律性の程度・支払責任者・停止権限は別途設計する。

## 3. 星空チケットとの一体化

- **独立の「星空チケット」サイトと、星空Village内のチケット販売・購入機能を両立する**。Village利用者がチケット購入のためだけに外部サイトを開く必要はない。
- **共通会員アカウント**：両サービスで同じIDと基本プロフィール（表示名等）を使う。一方で登録すれば他方は再登録不要。チケットのみの利用者にSNS参加・投稿を強制しない。
- **共通チケット基盤**：イベント、在庫、決済、購入履歴、チケット所有権、入場状態を正本で共有し、両画面で販売・購入しても二重販売しない。
- 他アーティストの公演は、本人が**公演単位でVillageへの掲載を選択（初期OFF）**。希望したイベントだけVillage内で発見・購入できる。ほしくん自身の公演もVillage内で提供する。
- チケットの料金・審査・実装条件の詳細は [星空チケット専用リポジトリ](https://github.com/HoshizoraArchive/hoshizora-village-tickets) の設計文書を参照。**これは統合構想であり、本番機能の実装宣言ではない。**

## 4. 長期的に統合したい生活圏

- Village内で遊べる**ゲーム**
- **DM・音声通話**
- **ライブ配信**
- **バーチャルイベント**、現実のライブ・イベントとの相互連携
- 創作、観測、交流、ゲーム、イベント参加といった体験を、同一アカウント・関係性・世界観の中でつなげる。
- 参考イメージは『サマーウォーズ』のOZや『超かぐや姫！』の仮想世界。ただし既存作品との提携や同等機能の実現を表明するものではない。

## 5. 開発フェーズの境界

- **現在**：星空Village本体のβ実利用検証と既存のAI観測・共鳴・セキュリティ品質を優先。
- **別系統で設計**：星空チケットは専用リポジトリで開発し、認証とイベント/購入の共通仕様を安全に連携。
- **将来**：ゲーム、DM通話、配信、イベント融合、AIの外部収益・還元は別々に実現性と安全性を検証して段階的に進める。

この構想は「他SNSに勝つ」こと自体が目的ではない。**創作者が人気だけに左右されず、誰かに観測され、創作を続けられる社会を育てること**を目的に置く。
